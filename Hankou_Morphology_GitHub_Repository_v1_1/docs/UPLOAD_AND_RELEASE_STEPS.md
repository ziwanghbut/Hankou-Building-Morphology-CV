# Upload and release steps

1. Create one Zenodo record.
2. Upload:
   - `Hankou_Morphology_Zenodo_Minimal_Data_v1_1.zip`
   - `Hankou_Morphology_Zenodo_Extended_Features_v1_1.zip`
3. Reserve or publish the Zenodo DOI.
4. Create a GitHub repository and extract the GitHub package into its root.
5. Replace `ZENODO_DOI_TO_BE_ADDED` and `GITHUB_URL_TO_BE_ADDED`.
6. Select the final data and code licenses.
7. Create the GitHub release tag `v1.1.0`.
8. Update the manuscript Data Availability Statement with the final DOI.
9. Do not upload raw photographs until image rights and privacy have been reviewed.
